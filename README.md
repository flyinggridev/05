# Flying Grid — EV Charging Partner Website

A responsive single-page website for Flying Grid, designed with a premium light theme, deep forest-green accents, clean typography, and mobile-friendly layout.

## Features
- Light premium visual theme with green brand accents
- 6kW DC dual-gun fast charger (3kW + 3kW)
- 3.3kW AC charger option
- Fixed Rent and Revenue Share partnership models
- Zero-host-investment message, subject to site assessment and written agreement
- Target locations: restaurants, cafes, shops, homes, societies, offices, hotels and parking lots
- WhatsApp enquiry form and direct email contact
- Responsive navigation and mobile call-to-action

## Files
- `index.html` — website page and styling
- `logo.png` — Flying Grid logo (keep in the same folder as `index.html`)

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `logo.png`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
